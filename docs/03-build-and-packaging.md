# 03 — Build & Packaging

From source tree to a bubble that installs and boots.

---

## 1. The chain

```
 CMakeLists.txt
   │  include(${VITASDK}/share/vita.cmake)
   ▼
 arm-vita-eabi-gcc ──▶ app.elf
   │  vita_create_self(eboot.bin app)          # sign as SCE SELF
   │  vita_create_vpk(app.vpk TITLEID eboot.bin VERSION… NAME… FILE…)
   ▼
 app.vpk ──VitaShell / FTP──▶ ux0:app/<TITLEID>/eboot.bin
                              ux0:app/<TITLEID>/sce_sys/…
```

`vita_create_self` has an optional `UNSAFE` argument. You need it only when you
patch code pages at runtime (Android `.so` loaders, hookers). VM-block JIT does
**not** need it — Play! builds without `UNSAFE` because it allocates its own RWX
region.

## 2. Minimal CMake

```cmake
cmake_minimum_required(VERSION 3.13)

if(NOT DEFINED CMAKE_TOOLCHAIN_FILE)
  if(DEFINED ENV{VITASDK})
    set(CMAKE_TOOLCHAIN_FILE "$ENV{VITASDK}/share/vita.toolchain.cmake" CACHE PATH "")
  else()
    message(FATAL_ERROR "Define VITASDK")
  endif()
endif()

project(Game C CXX)
include("${VITASDK}/share/vita.cmake" REQUIRED)

set(VITA_APP_NAME "Game Name")
set(VITA_TITLEID  "XXXX00001")
set(VITA_VERSION  "00.10")
set(VITA_MKSFOEX_FLAGS "-d ATTRIBUTE2=12")

add_executable(game src/main.cpp)
target_link_libraries(game vita2d SceDisplay_stub SceGxm_stub SceCtrl_stub
    -Wl,--whole-archive pthread -Wl,--no-whole-archive m stdc++)

vita_create_self(eboot.bin game)
vita_create_vpk(game.vpk ${VITA_TITLEID} eboot.bin
    VERSION ${VITA_VERSION} NAME ${VITA_APP_NAME}
    FILE sce_sys/icon0.png sce_sys/icon0.png
    FILE sce_sys/livearea/contents/template.xml sce_sys/livearea/contents/template.xml)
```

The four `VITA_*` variables are consumed by `vita.cmake` — misspell one and you get
a VPK with an empty title string that installs but shows garbage in LiveArea.

## 3. Compiler flags

Consensus across the reference projects:

```
-O3 -mcpu=cortex-a9 -mtune=cortex-a9 -mfpu=neon -marm
-ffast-math -fsingle-precision-constant -ftree-vectorize
-fno-unwind-tables -fno-asynchronous-unwind-tables
-mword-relocations -Wl,-q
```

Port-specific additions and why:

| Flag | Reason |
|------|--------|
| `-mfloat-abi=softfp` | only for loading Android binaries built softfp |
| `-fno-short-enums` | keep 4-byte enums when mirroring console ABI |
| `-fno-exceptions -fno-rtti` | smaller, faster; fine for engine-style code |
| `-fno-strict-aliasing` | game code type-puns |
| `-fwrapv` | signed overflow semantics |
| `-ffp-contract=off` | stop FMA from changing float results |

## 4. Deploy loop (the one that saves hours)

```powershell
cmake --build build -j8
curl -T build/eboot.bin ftp://$env:PSVITAIP:1337/ux0:/app/XXXX00001/eboot.bin
echo "launch XXXX00001" | nc $env:PSVITAIP 1338
```

Upload `eboot.bin`, never the VPK, for iteration. Port 1337 is VitaShell's FTP;
port 1338 is its launch command. Play! wires exactly this into CMake:

```cmake
add_custom_target(launch
    COMMAND curl -T ${PROJECT_NAME}.self ftp://$ENV{PSVITAIP}:1337/ux0:/app/${VITA_TITLEID}/eboot.bin
    COMMAND echo "launch ${VITA_TITLEID}" | nc $ENV{PSVITAIP} 1338
    DEPENDS ${PROJECT_NAME}.self)
```

## 5. VPK contents checklist

| Path | Required | Note |
|------|----------|------|
| `sce_sys/param.sfo` | yes | generated by `vita_mksfoex` |
| `eboot.bin` | yes | must be SELF, not ELF |
| `sce_sys/icon0.png` | effectively | 128×128, else no icon |
| `sce_sys/pic0.png` | optional | startup image |
| `sce_sys/livearea/contents/bg0.png` | optional | 840×500 |
| `sce_sys/livearea/contents/startup.png` | optional | 280×158 |
| `sce_sys/livearea/contents/template.xml` | optional | layout |
| `sce_sys/trophy/...` | for trophies | see doc 13 |

## 6. Common build failures

| Symptom | Cause |
|---------|-------|
| `vita.cmake not found` | incomplete SDK — `share/` missing |
| undefined `sceGxm*` | forgot `SceGxm_stub` |
| threads crash on start | `pthread` not linked with `--whole-archive` |
| `undefined reference to _newlib_heap_size_user` | forgot to define it |
| installs, black screen | not a SELF, or `ATTRIBUTE2` wrong |
| `cannot find -lvita2d` | third-party lib not installed |
